# Origin

This skill is an operational adaptation of the engineering guidance from:

https://github.com/elsewhencode/project-guidelines

The upstream project is licensed under MIT. This skill reorganizes and rewrites the guidance into an agent-oriented, modular skill format.

Agent Skills compatibility was designed around the current GitHub/Copilot skill layout:
- SKILL.md with YAML frontmatter
- optional referenced Markdown resources
- project placement under `.github/skills`, `.agents/skills`, or `.claude/skills`

Upstream repository: https://github.com/elsewhencode/project-guidelines
